# 🗄️ In-Memory Database System

A Python-based simulation of a **Relational Database Management System (RDBMS)** that manages data using primitive Python structures.

## ✨ Key Features
* **Core Operations:** Supports `CREATE_TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`, and `COUNT`.
* **Relational Logic:** Implements `JOIN` operations to combine data from multiple tables based on a common column.
* **Error Handling:** Robust management of non-existent tables or columns using try-except blocks.
* **Dynamic Rendering:** Custom table renderer for structured and readable terminal output.

## 🛠 Technical Stack
* **Language:** Python 3.9
* **Data Structures:** Lists, Dictionaries, and Tuples

## 🚀 Execution
```bash
python3 database.py input.txt
