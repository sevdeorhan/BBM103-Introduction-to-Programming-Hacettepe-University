📊 Text AnalyzerA Python-based tool developed for Hacettepe University BBM103 to perform basic Natural Language Processing (NLP) and statistical analysis on text files.✨ Key FeaturesTokenization: Extracts words while handling punctuations correctly.Statistics: Calculates total word/sentence counts and average words per sentence.Character Analysis: Measures total characters (with and without white-spaces).Frequency Mapping: Identifies the shortest/longest words and calculates the frequency of every unique word.🛠 Technical StackLanguage: Python 3.9.Core Concepts: String manipulation, File I/O, and sorting algorithms.🚀 ExecutionBashpython3 text_analyzer.py input.txt output.txt
